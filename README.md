I build practical tools for finance research, data analysis and everyday workflows. This portfolio brings together analytical projects and working software prototypes, with setup instructions and clear limits on what each project currently does.

## How to read the portfolio

Start with **Finance Desk** for finance and data modelling, **Briefly** for a relational web application, or **GymSesh** and **NoirTasks** for native app development. The R project shows an academic modelling workflow, including methodological limitations worth improving.

Each repository explains its purpose, setup and current boundaries. These are personal projects and prototypes; a published source repository does not imply a production deployment. Private records, credentials and local application databases are excluded.

Additional project: [SQE1 Study Hub](https://github.com/aryan2k1/sqe1-hub), a browser-based study app with spaced repetition and custom flashcards.
